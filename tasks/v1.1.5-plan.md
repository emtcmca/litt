## Architecture Decisions

1. **Architecture diagram rendered from React, not standalone HTML.** Build `ArchitecturePreview.tsx` at `/architecture` using existing `T` tokens and IBM Plex stack — then screenshot from the browser. This is faster than a headless render pipeline and guarantees font/color fidelity with the product.

2. **Sweep reliability via `Promise.race`, not bare inner try/catch.** The current `handleRun()` inner try/catch only catches thrown errors (backend down). It does not protect against a slow backend. `Promise.race` with a 4500ms timeout fixture fallback protects both cases.

3. **SweepStatusBar as a thin inline status chip in the Agent Console header**, not a separate panel. Appears during `loading` phase and shows `source` label after playback starts. Disappears at idle.

4. **ProofBlock `defaultOpen` driven by gate level, not item type.** ResolvePanel passes `gate={descriptor.gate}` to ProofBlock. ProofBlock auto-opens when `gate === 'ESCALATION' || gate === 'BLOCKED'`. No new ProofData fields needed — derive model/gate rows from existing data.

5. **Integrations expansion in-place** — no new component files. Update the `Integration` interface and `INTEGRATIONS` array in `Integrations.tsx`, add the MCP boundary panel below the tile grid.

6. **`/architecture` route is a capture-only route** — add to `App.tsx` router but not to `ConsoleRail.tsx` nav. Purpose: browser screenshot at 1920×1080. Can be removed post-submission.

#### Task 1.1 — Fix `handleRun()` with Promise.race timeout

**Description:**  
Replace the current inner try/catch in `handleRun()` with a `Promise.race` between the live API call and a 4500ms fixture fallback. Add `SweepPhase` and `SweepSource` types to drive status display. Add a `sweepSource` state to track whether the current playback came from the live API or the fixture.

**Files:**
- Modify: `dashboard/src/pages/AgentConsole.tsx`

**Specific changes:**

Add near the top of the component file (after imports, before constants):
```ts
type SweepSource = 'live-api' | 'demo-fixture';
type SweepPhase  = 'idle' | 'loading' | 'playing' | 'complete' | 'error';
```

Add `sweepSource` and `sweepPhase` state:
```ts
const [sweepPhase,  setSweepPhase]  = useState<SweepPhase>('idle');
const [sweepSource, setSweepSource] = useState<SweepSource | null>(null);
```

Replace `handleRun()` with:
```ts
const handleRun = useCallback(async () => {
  clearTimers();
  setSel(null);
  setError(null);
  setSweepPhase('loading');
  setSweepSource(null);

  const liveCall = runSweep(FIRM_ID)
    .then(res => ({ obs: res.timeline.observations as AgentObservation[], source: 'live-api' as SweepSource }));

  const timeoutFallback = new Promise<{ obs: AgentObservation[]; source: SweepSource }>(resolve =>
    window.setTimeout(() => resolve({ obs: sweepFixture as AgentObservation[], source: 'demo-fixture' }), 4500)
  );

  let obs: AgentObservation[];
  let source: SweepSource;
  try {
    ({ obs, source } = await Promise.race([liveCall, timeoutFallback]));
  } catch {
    obs    = sweepFixture as AgentObservation[];
    source = 'demo-fixture';
  }

  const steps = obs.map(adaptObs);
  setSweep(steps);
  setSweepSource(source);
  setStep(-1);
  setSweepPhase('playing');

  for (let i = 0; i < steps.length; i++) {
    const id = window.setTimeout(() => {
      setStep(i);
      if (i === steps.length - 1) setSweepPhase('complete');
    }, (i + 1) * STEP_MS);
    timers.current.push(id);
  }
}, []);
```

Update `pause()` to set `setSweepPhase('idle')` when paused mid-sweep (or keep at 'playing' — acceptable either way; document choice).

Remove the `isRunning` state if it's no longer needed (replaced by `sweepPhase === 'loading'`). Update the run button's `disabled` and `opacity` to use `sweepPhase === 'loading'` instead of `isRunning`.

Update the run button label logic:
```ts
// button label
sweepPhase === 'loading'  → <spinner> + "Starting sweep..."
playing                    → pause icon + "Pause"
step === sweep.length - 1  → refresh icon + "Replay sweep"
step >= 0                  → refresh icon + "Resume"
default                    → refresh icon + "Run closeout sweep"
```

**Acceptance criteria:**
- [ ] Clicking "Run closeout sweep" shows a visible status change within 250ms
- [ ] A trace begins within 5 seconds regardless of backend state
- [ ] Button is never stuck disabled after the timeout fires
- [ ] "Replay sweep" label appears after the final step
- [ ] "Pause" label appears during playback
- [ ] `npm run build` passes with no TypeScript errors

**Verification:**
- [ ] With backend running: trace plays from live API, `sweepSource` is `'live-api'`
- [ ] With backend stopped: trace plays from fixture within ~5s, no error visible to user
- [ ] Manual: click Run, observe button state transitions through loading → playing → complete
